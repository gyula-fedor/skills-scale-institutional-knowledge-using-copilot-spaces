## Project Lifecycle

OctoAcme projects follow a structured lifecycle:

1. **Initiation** - Validate the need, align stakeholders, define success metrics
2. **Planning** - Break work into actionable items, identify dependencies, create timelines
3. **Execution** - Deliver incrementally, track progress, manage risks and blockers
4. **Release** - Deploy to production, verify, communicate outcomes
5. **Retrospective** - Capture learnings and drive continuous improvement

## Key Principles

OctoAcme project management is built on these core principles:

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning
